## Estructura del proyecto

- infraestructura/: configuración de red y máquinas virtuales
- kubernetes/: manifiestos de despliegue de servicios
  - odoo/
  - postgresql/
  - traefik/
  - longhorn/
  - monitorizacion/
- docs/: documentación, capturas y memoria

- K3s (Kubernetes)

- Longhorn

- Grafana
