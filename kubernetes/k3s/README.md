# K3s

Archivos relacionados con el estado general del cluster.

| Archivo | Contenido |
| --- | --- |
| `nodes.txt` | Nodos del cluster y version de K3s |
| `namespaces.yaml` | Namespaces principales utilizados |
| `current-status.txt` | Estado actual de pods, PVC e Ingress |
| `helm-releases.txt` | Releases Helm instaladas |

Estos archivos se han exportado desde el nodo `k3s-master` como evidencia del estado real del entorno.
