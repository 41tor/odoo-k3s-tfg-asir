# PostgreSQL

Manifiestos y recursos relacionados con la base de datos de Odoo.

| Archivo | Contenido |
| --- | --- |
| `postgresql.yaml` | Manifiesto principal de PostgreSQL |
| `postgresql-resources.yaml` | Recursos exportados desde el cluster real |

PostgreSQL se despliega en el namespace `postgresql` y utiliza un volumen persistente gestionado por Longhorn.
