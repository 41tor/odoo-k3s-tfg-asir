# Monitorizacion

Recursos relacionados con Prometheus, Grafana y la publicacion de Grafana.

| Archivo | Contenido |
| --- | --- |
| `grafana-ingress.yaml` | Ingress de Grafana |
| `monitoring-resources.yaml` | Recursos principales exportados desde el namespace `monitoring` |

El stack de monitorizacion se despliega mediante Helm con `kube-prometheus-stack`.
